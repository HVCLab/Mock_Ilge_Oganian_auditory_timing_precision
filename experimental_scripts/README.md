## Experimental Scripts
This folder contains the MATLAB scripts and supporting materials used to run the behavioral experiment reported in the manuscript.  


### IAP.m
- script to run Iterative Adjustment Paradigm (IAP)  
- **dependencies:** calculateNewAudio.m, createExperimentalSeq.m, createShifts_nonspeech.m, createStimuli.m (custom functions part of this repo)  
- requires Psychtoolbox, last run with version 3.0.18 on Matlab R2022b
